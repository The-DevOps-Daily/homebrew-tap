# DevOps Daily Homebrew tap

Homebrew casks for [DevOps Daily](https://devops-daily.com) tools.

```sh
brew install The-DevOps-Daily/tap/devops-daily
```

That installs `devops-daily` and its short alias `ddy`. The casks here are
written by each release of
[devops-daily-cli](https://github.com/The-DevOps-Daily/devops-daily-cli); do
not edit them by hand.
